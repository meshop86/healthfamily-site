Emergency Feature

Medical info
when it matters most

The emergency screen displays the most critical information — no password needed. First responders can access it instantly.

✓ Blood type and drug allergies on the first screen
✓ Current medications and chronic conditions
✓ One-tap Emergency Call button for family contacts
✓ Automatically updated when you log in
🔒 Integrates with iOS Medical ID — first responders can call emergency contacts directly from the lock screen, no passcode needed. On iPhone: Settings → Health → Medical ID → Edit.
